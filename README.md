# リバーシ

Delta Chat のチャット内で遊べる webxdc アプリです。CPUとの1人対戦と、チャットメンバー同士のオンライン対戦に対応しています。

- バージョン: **1.1.3**
- 配布ファイル: `reversi-1.1.3.xdc`
- 表示言語: 日本語

## はじめ方

1. Delta Chat の対戦したいチャットに `reversi-1.1.3.xdc` を添付して送信します。
2. チャット内のアプリを開きます。
3. モード選択画面で、CPU対戦または「チャット相手と対戦 (オンライン)」を選びます。

オンライン対戦では、両者が**同じチャットの同じアプリメッセージ**を開いてください。別々に送信したアプリでは対戦を共有できません。

## 遊び方

8×8の盤面で、黒と白が交互に石を置きます。黒が先手です。自分の石で相手の石を縦・横・斜めに挟むと、挟んだ石が自分の色になります。

- 自分の手番では、置けるマスに小さな目印が表示されます。
- 最後に石を置いたマスは黄色い枠で表示されます。
- 置ける場所がない場合は自動でパスします。
- 両者とも置けなくなると終了し、石の多い方が勝ちです。同数なら引き分けです。

## CPU対戦

モード選択で、自分が黒または白になるボタンを選びます。CPUは角を優先し、それ以外の合法手からランダムに選びます。難易度の選択機能はありません。

CPU対戦の操作はチャットへ送信されません。終局後は「最初からやり直す」で再開できます。メニューに戻ってCPU対戦を選び直すと、新しい対局になります。

## オンライン対戦

1. 「チャット相手と対戦 (オンライン)」を開きます。
2. 「黒で募集」または「白で募集」を押します。
3. 相手も同じアプリを開き、「参加する」を押します。
4. 自分の手番になったら、目印のあるマスをタップ／クリックします。

募集者は、参加者が来る前なら「募集をやめる」で取り下げられます。両者が同時に募集すると、自動で組み合わせが決まり、対戦が始まります。表示された自分の色を確認してください。

### 観戦・投了・再戦

- グループチャットなどの対戦に参加していないメンバーは、同じアプリから観戦できます。
- 対戦中に「投了」を押すと確認表示に変わります。3秒以内にもう一度押すと投了が確定します。
- 終局後、参加者が「もう一度 (色を交代)」を押すと、同じ相手と黒白を入れ替えて再戦が始まります。相手の承諾を待つ画面はありません。
- 「新しく募集する」から、新しい対戦を募集できます。
- 「メニューに戻る」は画面を切り替える操作です。オンライン対戦の投了や募集の取り下げにはなりません。

## 通信と状態の復元

オンライン対戦では、募集・参加・着手・投了・再戦などを webxdc の更新として共有します。対戦状態は更新履歴から復元されます。

画面下部には受信件数、最後の受信時刻、アプリのバージョンが表示されます。通信状況によって更新の到着に時間がかかる場合があります。

### 相手の募集や着手が表示されない場合

- 両者が同じチャットの同じアプリメッセージを開いているか確認してください。
- Delta Chat の通信状況を確認し、更新が届くまでしばらく待ってください。
- 画面下部の受信件数や最後の受信時刻を確認してください。
- 「テスト表示」と出ている場合は、通常のブラウザではなく、Delta Chat 内でアプリを開いてください。

## パッケージの内容

`.xdc` はZIP形式のパッケージです。この配布ファイルには次の3ファイルが含まれています。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面、スタイル、ゲーム処理、通信処理 |
| `manifest.toml` | アプリ名、バージョン、起動HTMLなどの設定 |
| `icon.png` | アプリアイコン |

`webxdc.js` はHTMLから参照されていますが、このパッケージには含まれていません。webxdcの実行環境が提供するAPIを利用します。

## 通常ブラウザでの動作確認

展開した `index.html` を通常ブラウザで開き、webxdc APIがない場合はテスト用モックが有効になります。CPU対戦を試すことができ、BroadcastChannelが利用できる同じブラウザ・同一オリジンの別タブ間では、オンライン対戦の擬似通信も行えます。

このテスト表示では別端末と通信できません。モックは更新履歴を保存しないため、ページを再読み込みしてもオンライン対戦の状態は復元されません。
